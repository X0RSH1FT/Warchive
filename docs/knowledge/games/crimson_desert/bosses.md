# Crimson Desert Bosses

Last checked: 2026-11-13 | Base game patch: 2.05.00 | Evidence: official for system-level claims; guide and community-index rosters, partial | Return to the [index](README.md)

Researched catalogue, not an exhaustive one. No publisher-maintained boss database and no authoritative total boss count were found. Every roster below is partial, and the sources' counts conflict.

## Catalogue status

| Measure | Value |
|---|---|
| Item-level entries on this page | 20 named encounter rows (some are context-only, such as the Sea Serpent) |
| Source-reported sizes | CrimsonDesert.app boss directory: 104 entries. Its companion location article: "57 total bosses", 28 main story. Gaming.tools Knowledge: 87 Bosses. Search snippets claimed 75, 88, and 127 (not verified) |
| Method | Names read from the app's boss directory (13 visible records), IGN's side-boss list (3 names), Pearl Abyss notices, and DLC gear records that name a boss and a quest |

## Boss counts and conflicts

| Official DLC notes | Not stated | The update adds several bosses and Memory Fragment rematches without a named roster ([PATCH-2.04.00]) |

A 2.04.00 official note states that the DLC adds several bosses and boss rematches using Memory Fragments; Memory Fragments are discussed in [collectibles-resources.md](collectibles-resources.md).

## Excluded or unverified claims

- Per-boss difficulty, healing, drop, and respawn data from the fan companion page are not recorded as facts: its extracted table had inconsistent names and regions and contradictory counts ([FAN-BOSS]). Only boss names from the app directory are recorded, with its counts shown as attributed claims above.
- IGN's side-boss list says it contains what has been "discovered so far" (updated 2026-06-30); it does not establish a total across story, field, DLC, or rematch bosses.
- The item ID of Aeserion's Scale contains "snake_boss_scales", which suggests a snake boss named Aeserion; no source in the research confirms such a boss, so it is not listed above.

## Coverage limitations

- No complete roster, boss-to-location map, phase descriptions, or drop tables; level and location are missing in many app rows.
- Boss classification (story, side, field, DLC) is stated only for the three IGN side bosses and, loosely, for DLC-related rows.
- No source established encounter steps, drop tables, or conditions for every named major encounter.

## Patch-sensitive caveats

- Retry behavior changed in 2.05.00; older advice about restarting fights may be outdated.
- Rematches were extended after launch; the list of rematchable bosses is not given.
- Boss behavior may have been adjusted in patches not covered by the digest.
