# Crimson Desert Systems and Progression

Last checked: 2026-11-13 | Base game patch: 2.05.00 | Evidence: official for named features; guide-reported for mechanics | Return to the [index](README.md)

## Progression model

| Element | What is supported | Status | Source |
|---|---|---|---|
| Abyss Artifacts | Guide: skill-point style currency spent on skills and stat upgrades; guide also says gear refinement consumes them. PlayStation's preview says they unlock character upgrades and abilities. | Medium; see conflict note in [equipment-enhancements.md](equipment-enhancements.md) | [IGN-SKILLS], [PS-BLOG] |
| Observation learning | Guide: some abilities can be learned by observing them | Medium | [IGN-SKILLS] |
| Separate skill trees | Guide: Damiane and Oongka have their own trees with some shared stats | Medium | [IGN-TIPS] |
| Not a traditional level system | IGN's framing; no official manual confirms the model | Medium | [IGN-SKILLS] |

Abyss Artifacts and Abyss Gears are different things. See [items-materials.md](items-materials.md).

## Core feature areas (official, broad)

Greymane camp upgrades, gathering, cooking, fishing, hunting, equipment strengthening, and minigames are named in the official store text ([STEAM-BASE]). Equipment progression and combat were also presented in an official prerelease overview ([FEATURES-2]).

## DLC systems (Charting the Unknown)

Ship-based ocean and island exploration, diving, underwater treasures and ruins, facility rental and management, expanded housing, and deeper NPC bonds. Base game is required; Steam lists release 2026-10-29 ([STEAM-DLC], [OFF-DLC]).

## Guide-covered practical systems (medium confidence)

IGN covers housing, inventory, food, crime and bounties, contribution, camp operations, and fast travel. The housing page was updated 2026-10-21 and documents updates through 1.12 ([IGN-HOUSING]); the tips page dates to 2026-03-23 and contains older patch-specific advice ([IGN-TIPS]). Use them as leads; no numeric values are recorded here.

## Coverage limitations

- No official manual for crafting recipes, storage capacity, camp or comrade assignments, fishing, farming, management profits, or crime consequences.
- The digest skips versions; features added in versions it omits are unknown here.
- Exact numbers (costs, capacities, rates) are intentionally absent.

## Patch-sensitive caveats

- Exact prices and material counts changed in 2.05.00 without published values; check in game.
- Known Issues (updated 2026-11-13) includes intermittent interaction failures, some underwater audio problems, and platform-specific UI issues ([KNOWN-ISSUES]). Evasion remapping with Evasion Control set to Hold is also reported; see [character-moves.md](character-moves.md).
